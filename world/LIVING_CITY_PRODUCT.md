# Living City product integration contract

Owner: Product. Other owners may read; Product edits this file.

Worker inspector: `mountWorkerInspector({container,registry,capabilities={},actions={},getContext=()=>({})})` returns `{update,destroy}`. Registry should expose `snapshot()` or `getSnapshot()` with `{workers:[],pools:[],errors:[]}` and optional `subscribe(callback)` returning unsubscribe. Worker rows use real `id,type,status,createdAt,currentTask,tasksCompleted,tasksFailed,avgTaskMs,queueDepth,lastHeartbeat,progress,ownership`. No workers are manufactured. Capabilities are explicit named booleans and must match supplied action callbacks: `drainWorker(id)`, `restartWorker(id)`, `terminateWorker(id)`, `pausePool(id)`, `resumePool(id)`, `setPoolSize(id,count)`; no control is available by default. Termination requires an inline explicit confirmation. `world:worker-show-work` bubbles with `{workerId,type,ownership}` only when actual ownership exists; Viz must interpret the declared spatial/range data, not invent a highlight.

Session model: `createDecisionSession({sessionId='living-city',clientId?,channelFactory?,maxEvents=500})` returns `{record(type,payload),getState(),subscribe(fn),setFollowing(bool),publishViewpoint(view),present(),annotate(target,text),ask(text),createExperimentTask(questionId),export(),import(data),replay(onEvent),destroy()}`. Browser channel default BroadcastChannel; explicit `channelFactory:null` disables communication. Versioned bounded log, same-origin tabs only. No backend/cross-device collaboration. Imported/replayed events never invoke an edit or an approval.

Session UI: `mountSessionView({container,session,getViewpoint,onFollowViewpoint,onExperimentTask})` returns `{update,destroy}`. `update({viewpoint})` can publish a throttled actual camera view. Viewpoint `{position:[x,y,z],target:[x,y,z]}`. `onFollowViewpoint(view,event)` is called only for a new live presenter viewpoint when Follow is enabled. `onExperimentTask(task)` receives a queued question, not an approved experiment. UI never invokes simulation/approval itself.

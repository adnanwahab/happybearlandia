Coverage by domain and record type

Each denominator counts the eligible events or observations in that row. An incoming causes, contributes, or constrains edge with a resolvable source counts as linked. Statistical associations are excluded. These links describe the recorded model.

Supporting evidence requires a linked edge with recorded provenance and at least one evidence reference, with every reference on that edge resolved. Record provenance counts provenance on the event or observation itself.

Missing link means the check found no qualifying dependency. Unknown means a failed or bounded check or an unresolved reference left that result undetermined. Coverage for an incomplete run reflects only its stored records at the displayed revision.

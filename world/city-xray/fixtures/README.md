# City X-Ray contract v1 diagnostic

`cityFixture(0)` produces immutable synthetic demonstration geometry with a separate local LCG, 289 intersections, 544 roads, 4096 authored places, 4095 finite intensities (including zero), and one explicit missing value. No resident agents, vehicle ledgers, utility topology, model advancement or observed geography. Model/source/schema/generator versions are pinned in each frame. Reproduction requires this generator version and seed; IDs remain stable across seeds, run identity changes.

`readFrame` validates and detaches plain JSON; returns deeply frozen data. Consumers must pass expected identity/clock/coordinates when joining frames (`readFrame(candidate, {identity: original.identity, clock: original.clock, coordinates: original.coordinates})`). Equal local IDs alone never authorize a join. `frameHash` is SHA-256 of lexicographically key-sorted canonical JSON; array order is significant. Unknown JSON metadata remains hash-bound. Boundaries are fail-closed, including NaN, infinity and absent fields. No automatic coordinate/time conversion exists. Local model units are deliberately not metres.

SHE161 semantics: `world/population/city-heatmap.js` occupancy count is raw synthetic residents; representedCount = count × model weight. Activity counts retained encounters once, unweighted, in `(max(0, minute-30), minute]`, at most 120 records citywide; unmapped records are disclosed. Those are **not** this fixture's synthetic-symbols metric. A future Population adapter must explicitly carry that retention/window and source checkpoint. Monthly City uses months; no minute/month conversion is supplied. This slice does not claim an adapter to either engine.

Each metric pins quantity, units, exact clock/checkpoint, fixed normalization and null sample count. Every sample must join a geometry ID and the same run. `representedCount:null` means unavailable, not zero. Display symbols are a budget distinct from represented population. Contract v1 supports only places/roads/intersections, no vehicle or utility claims. Coordinates are `[x,y,z]`, east/up/south with explicit local origin.

Open `preview.html` through the focused browser harness. The Canvas2D angled aerial is a static diagnostic for downstream columns/particles, not the final GPU effect or a performance benchmark. Colour = authored intensity / 100; short vertical accents are the same diagnostic metric in screen pixels, not physical height. No external tiles/assets. No observed or recorded model data. Reference download.png was not available in this worktree; human comparison remains required. GPU frame time and memory: NOT RUN.

The read boundary counts canonical UTF-8 bytes incrementally (12,000,000 maximum), with a 1,000,000-node traversal budget before clone/hash allocation. Nonenumerable fields and arrays with custom properties are rejected rather than silently lost.

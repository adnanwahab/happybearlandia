# Historical authority replay

`engine.js` exposes `HistoricalStateService`, `ReplayAdapterRegistry`, `createReplayCheckpoint`, `verifyReplayCheckpoint`, and SHA-256 `canonicalDigest`. This is a domain replay engine; the shared `ReplayAdapter` is a UI playback controller. Context uses the foundation RunContext; scenarios identify experiments and run IDs identify branches. No local branch identity is inferred.

Register an exact domain/modelVersion/adapterVersion tuple. Adapters encode *complete* JSON authority (including RNG cursor/seed, queues and stocks), restore a private state, and explicitly apply replayable events. They may supply `getTick`, `advance`, and `recompute`. The City adapter uses the existing CityState.v1 monthly engine. It supports autonomous recomputation; intervention histories fail until a versioned intervention replay implementation exists. Legacy/population checkpoint formats are not implicitly interchangeable with CityState.

Persist an envelope produced by `createReplayCheckpoint` as the shared Checkpoint record's `state`, with the same context/tick. The shared record's hash and immutable store contentHash are separate from the envelope's hash over its complete identity, scope, tick, versions and serialized authority. State digest hashes only adapter-serialized authority. Adapters must exclude UI, wall clocks, rendering resources and recorded AI text from this projection. The engine rejects nonfinite and non-JSON values rather than silently changing them.

Replay event records use `payload.replayEvent = {id,context,tick,sequence,domain,modelVersion,adapterVersion,replayKind,type,payload}`. Kinds are `input`, `transition`, `narrative`, `render`, `wall-clock`. Unclassified/descriptive records fail closed when in the replay interval; AI narrative, render and wall-clock records never enter recomputation. Persist digest records with `type: 'replay.state-digest.v1'` and payload `{context,tick,domain,modelVersion,adapterVersion,digest}`. Verified recomputation requires an independently recorded digest at the requested target, not a digest generated by the replay request itself.

`createReplayRepository(store.causality)` reads immutable paginated records and verifies content hashes. `createStoredHistoricalStateHandler(store.causality)` returns an HTTP handler for GET `/api/causality/state?context=<JSON RunContext>&tick=<integer>&mode=recorded-playback|verified-recomputation&checkpointId=<optional ID>`. A missing checkpoint returns 404; incompatible or unverifiable authority returns a structured error, never live-state fallback. `service.timeline` exposes ordered recorded history and checkpoint metadata; the universal inspector owns the public timeline route.

The latest checkpoint at or before target is selected by tick, with ID as deterministic tie-break; explicit checkpoint ID pins selection. Hash failure never falls back to an older checkpoint. Events at the checkpoint tick are already reflected in the checkpoint and are excluded; only `(checkpoint.tick, targetTick]` events apply. Input producers must checkpoint after all events at that tick. Duplicate IDs or tick/sequence positions fail. Recorded playback reports `verified: false` even if its output digest matches; only independent model recomputation earns `verified: true`.

# Reality Compiler coverage audit

Reality Compiler is an executable, inspectable synthetic-policy workspace at `/reality-compiler` (also `/city-speaks`). It selects reviewed mechanisms from bounded ordinary-language candidate rules. It does not compile arbitrary prose into a complete society, adjudicate law, enact policy or produce calibrated forecasts.

Existing daily legacy, Living population and monthly Constitution City authorities remain separate. A Reality experiment runs an isolated city or population lane from frozen initial inputs; it never becomes a second writer of live-world money, jobs or movement. Imported footprints locate geometry, while household inventory, district partitions, capacities, routes and finances remain model assumptions.

## Verification ledger

`test/e2e/reality-compiler.e2e.js` contains seven focused browser cases: actual1000-run catalog/replay, compiler/branches/persistence, real page and observation isolation, hotspot projection, indexed regional coverage, Challenge/Break/fix, and real pointer-driven regional fork creation/opening. The first six passed together in10.3seconds; the strengthened painted-region/opened-fork case subsequently passed in39.4seconds against production modules. The earlier population manifest double-normalization failure was fixed; compiled ordinary-language programs now execute through actual workers.

Additional branch semantic tests passed3tests/14assertions. Tests use actual worker modules and production transitions, with deliberately bounded fixtures and no fabricated successful-run counters. No paid inference, commits, deployments, GitHub changes or authority cutovers were performed. QA uses isolated port3146 and stops its server after each run.

Later child-agent gameplay additions require separate checks for actual parent/household links, child work constraints, school/sleep schedules, affordable care and parent work availability, seasonal camp capacity, permissions and deterministic restore. They are not certified by the Reality Compiler tests above.

## What’s causing this?

The constraint inspector below an entered world supports monthly city projects, businesses and households. Selecting an entity, or clicking its city marker, observes the chosen branch's exact saved month. A fresh worker simulates the next month to expose recorded delay reasons, entity fields and shared capacity usage; it does not invent a cause when none is recorded.

Choose one shared capacity/interest-rate input, a selected business's operating cost, or its household's current home rent, and compare two deterministic continuations from that same saved state. The result shows actual completion months (or a censored “not completed” result), city spending and entity outcomes. Other bottlenecks can make a proposed change ineffective. Cancel or select another source to terminate the isolated worker; neither continuation mutates the saved world.

Cost/rent changes are exogenous what-if inputs, not enacted regulations or funded subsidies. Shared capacity expansion has no staffing purchase ledger; the displayed city spending is model output, not the implementation price of that expansion. Population-lane futures explicitly report that this city-ledger inspector is unavailable. Tests cover actual permit/labor bottlenecks, deterministic completion, entity-level inputs, saved-state preservation and the real browser worker/UI flow.

## Probability clouds (SHE-224)

In an entered future, expand Probability clouds and enable presence frequency as
opacity. The overlay uses every located modeled structure in the selected arm
at one shared checkpoint, across up to 100 actual completed replays. The legend
states the denominator and seeds; individual records retain contributor IDs.
Opacity is exactly present futures / selected futures: zero is omitted and one
is opaque. WebGL uses RGBA vertex attributes in the existing two batches; the
existing SVG fallback groups exact counts instead of rounding into color bins.
`drawEnsembleCanvas` is also available to Canvas hosts with a caller-owned
transform and clearing. The current population view continues to use SVG.

These are synthetic scenario frequencies, not calibrated probabilities. Unmodeled
or unlocated structures remain coverage gaps. Overlapping strokes composite;
pixel brightness is not itself a frequency. Geometry is a footprint or anchor,
with no invented building heights. City-scale readability and the five-person
comprehension test remain product research gates.

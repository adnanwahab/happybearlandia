How the layers talk to each other

01 · Regions are hexagons

Every region is a set of H3 cells. A country uses resolution-2 cells about 300 km across; a block uses resolution-8 or finer, a few hundred meters. Deck.gl's H3ClusterLayer merges each set into one outline.

02 · Votes roll up

A city's tally for its question is the sum of what each neighborhood said. The map colors each sub-region by its own yes share, so you can see where support comes from before you read the total.

03 · Journals roll up too

An entry you write on your block also appears in the neighborhood, city, country and global journals, tagged with where it came from. Higher levels read the ground truth; lower levels see what the wider question is.

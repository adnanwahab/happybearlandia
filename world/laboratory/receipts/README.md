# Policy Impact Receipt

Open `/world/laboratory/receipts/` to run the same local, read-only 100-pair Riverside commute experiment as Living City. Enter a scenario seed or select one of the existing capacity proposals. Both arms of a pair share the starting state, seed, and scheduled flood. The view discloses the policy's proposed capital cost, district, and recorded end-of-horizon stages. The reported city balance change reflects the complete model for the interval.

The promise is a shorter recorded commute for the quest resident at month 14 compared with the baseline in the same pair. The distribution counts model pairs, with missing trips reported separately. It does not identify additional residents who benefit or lose, attribute the balance change solely to project cost, or estimate real-world effects.

Selecting a pair updates the shareable `challenge` URL and links to the corresponding Living City replay. Both routes use the same combined quest and City model version, initial seed, capacity amount, pair index, and fixed 12-month horizon. The receipt writes no experiment or production records.

Run `bun test test/policy-receipt.test.js`.

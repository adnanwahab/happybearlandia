    How agents update

    Eight districts start with different proposal preferences. Each agent gives their initial preference a private weight of one to two votes and counts one vote from every contact. A tied result preserves the current choice. Openness controls the chance that an agent follows a clear winner in each round.

    The question and proposal names label a seeded synthetic model. The same settings reproduce the same rounds.

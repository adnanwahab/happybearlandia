# House drama facade

Factory: `createHouseDramaSystem()` from `house-drama-system.js`, registry ID `house-drama`. Register after social and Story Director. No new completion/interval hooks: Story Director owns completed activity evidence, wants, argument secrets and gossip transfer; relationship core owns witnessed jealousy/directed resentment; party-chaos owns parties; Story object-history owns counters. No duplicate outcomes, scores, emotions or secret registry.

Default `inspect(model,home)` exposes `{schemaVersion,minute,people,knowledge:null,recap,highlights,forecast,objects,relationships,commands,limitations}`. Public inspection deliberately contains no secret text. `inspectHouseDrama(model,home,{personId?,day?})` is exported for selected-person projection. Only actual current household members can request private knowledge. Moved-out identities in historical provenance remain actual model identities, not active household rows.

Commands through normal household system dispatch, `{system:'house-drama',householdId,...}`:

- `{type:'knowledge',personId}` -> `result {personId,name,private:true,secrets,source}`. Secret rows reference the EXISTING canonical social secret ID/text/source/knownBy; player-authored fiction remains explicitly labeled. Completed-gossip transfer edges retain fromId/toId/minute/actionId and display names. This is read-only.
- `{type:'author-secret',personId,text,commandId}` -> delegates existing social `revealSecret`; text max160; stable receipt prevents duplicate authorship after reload. Never claims the fictional report is a canonical job/romantic fact.
- `{type:'gossip',personId,targetId,commandId}` -> checks actual actionAvailability, then starts normal `{type:'conversation',personId,personIds:[personId,targetId],conversationChoice:'gossip',topic:'day',durationMinutes:30}`. No knowledge transfer at button press. Existing Story Director chooses a secret known before action start and transfers only on actual attended completion. No caller-selected secret is promised. Existing activity gate governs co-location/schedules/queues.
- `{type:'interesting'}` -> exact delegation to existing Story Director with its canonical context actionAvailability/startAction; no extra reward, invented event or forced outcome.
- `{type:'predict'}` -> `houseDramaForecast(model,home)`: exactly three branches with label/condition/source/kind:'conditional'/probability:null, horizon180, empirical:false. No fork ensemble is run, no calibrated percentage is invented.
- `{type:'recap',day?}` -> `houseDramaRecap(model,home,day)`: actual retained Story, life and relationship event timeline (96 max) with source/action IDs, funniest actual joke or null, biggest ranked recorded moment or null, retention explanation, Watch Tomorrow callback metadata. No invented jokes when none occurred. Date/time stays unchanged.

The optional state `home.systems.houseDrama` stores only16 replay receipts under12KiB, not copied events/secrets/people. Inspect is pure. Existing secret transfer and object counters remain their single authorities.

UI: `mountHouseDrama(container,{onCommand,onWatchTomorrow})` from `house-drama-ui.js`; returns `{update({drama}),open(),destroy()}`. `onCommand` receives system:'house-drama' command; return `{accepted,result}` or result. Stable select/buttons survive live updates. Default private section is empty; selection fetches member knowledge and switching clears previous text immediately. Refresh private knowledge requests a fresh snapshot. Root may also supply `drama.knowledge` for selected member on updates. Provenance raw details carry data-house-advanced. Watch Tomorrow invokes callback only; root implements authoritative observation/persistence. Missing callback disables button. Panel is an inline section, not modal and does not pause time.

Integration privacy note: older story-ui Who knows? currently renders all `story.secrets`; hide that legacy diagnostic section in ordinary player view if strict selected-person privacy is required. Legacy social `shareGossip` directly changes knownBy after same-location checks; this facade does not use it. Completed-conversation provenance is available for actual Story gossip transfers; old direct shares are not misrepresented as completed conversations.

Verification: `bun test world/house/house-drama-system.test.js world/house/story-director.test.js`; Chromium `test/e2e/house-drama-ui.e2e.js`. Tests cover private projection, real argument/gossip completion and once-only transfer, actual action gate, receipt/reload, sourced recap, conditional forecasts, witnessed jealousy projection, canonical object counts, stable UI and Watch Tomorrow delegation.

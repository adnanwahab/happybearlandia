AgentGraph reads any of these JSON shapes:

  • AgentGraph runs: {"runs":[{"name","spans":[…]}]} or a single {"spans":[…]}
  • Spans: id, parent_id, agent, kind (agent|llm|tool|wait), start, end, model, tokens_in, tokens_out, cost, status, decision; times can be seconds, ms, ns or ISO strings
  • OpenTelemetry OTLP/JSON (resourceSpans) with GenAI semantic conventions. Each traceId becomes a run

## Delivered behavior and decisions

Only active nonembedded 3D Living World with original building geometry receives
cards; tile view, legacy and missing clock/context are silent. Use the camera
orbit target on the ground, rather than elevated camera position. Match exact
context district bounds/name; display only existing synthetic partition names.
A 700ms dwell plus 8m hysteresis suppresses repeated boundary crossings. These
values are UI assumptions beside their mechanism. Repeat the current district
only after another stable district arrival. Initial arrival is supported.

Cards last 4.5 seconds, contain captured Population modeled day/time, synthetic
partition/resident label and supplied geometry source. There is no wall-calendar
claim or model-result interpretation. Static layout applies to both motion
preferences; pointer events pass through, focus stays on existing controls, and
role=status uses polite atomic announcement. No input interception, model clock,
seed, source ID, run ID, RNG, output or persistence changes. Unsupported frames
clear state/contents; pagehide destroys DOM/style. Original loaded partitions
remain authoritative when map geometry streams; no new streamed districts are
invented.

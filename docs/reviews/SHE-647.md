## Next integrated slice

A **walking-only model-network compass is feasible with local implementation**;
it does not require a live transit feed or a retained executed-trip ledger.
Absence of a compass adapter is missing implementation, not an external blocker.
It must explicitly describe the current bidirectional synthetic sidewalk rules;
it cannot claim surveyed pedestrian access or imported direction restrictions.
Street transit reachability remains unsupported until a model-owned stop/link,
boarding/transfer and direction contract exists. An external feed alone would
not connect that contract to this model.

1. Own one read-only query in the selected World authority and its worker/runtime
   transport. Pin run identity, model/rules version, seed, tick/minute, source
   geometry revision, supplied resident position and effective walking speed.
   Querying must neither advance the model nor consume behavior randomness.
   Preserve Legacy and Population authority boundaries.
2. Compute a bounded shortest-path frontier over actual outgoing edges. Declare
   maximum graph size/work, time/distance budget and attachment rules. Include
   partial reachable edge segments at the budget boundary, not a radius circle
   or just destination dots. Validate finite positive speed; absent speed means
   unavailable time reachability. Do not turn incomplete work into a complete
   isochrone. Preserve source building IDs and supplied access coordinates;
   disclose estimated connectors and reject unsupported attachment.
3. Wire the selected resident inspector on `/world` to the query. List only
   supported destinations within budget. Selecting one opens the exact computed
   route and its assumptions without issuing a resident movement command.
   Reject stale replies after selection/run/tick changes. Provide explicit
   unsupported mode, missing geometry/speed, empty results and query failure
   states with retry. Do not fabricate coordinates for absent entities.
4. Bound overlay geometry and update work. Prefer static frontier/route lines;
   reduced motion must retain the full route and controls. Instrument actual
   frame intervals and overlay update cost separately from simulation time.
   Cancel pending work and dispose listeners, geometry and materials on close,
   run change and route exit. Restore focus to the invoking control.

Acceptance evidence still needed: unit tests for directed edges, disconnected
components, boundary equality/partial edges, connector limits, missing/nonfinite
speed, malformed graph and work exhaustion; deterministic and nonmutating
queries; integration tests for destination identity/route selection, stale
responses and errors; normal-entry Playwright success/unsupported/failure paths,
mobile controls, keyboard focus and reduced motion. Record actual pacing and
cleanup evidence. Desktop emulation must not be labeled physical mobile testing.
Material risks are straight-line fallback leakage, unbounded projection,
stale-run routes, invented access restrictions and cross-authority state joins.

## Decisions and evidence

Demand is not a published housing metric. The v1.2 annual-accounting event retains
households, while annual snapshots retain housing_supply. Both are synthetic
aggregate results. The adapter joins exact years/months and assumes one home per
modeled household. It does not reconstruct demand from vacancy or proxies. Year
zero lacks a household ledger and is omitted. Crossing timing is linear
interpolation between supported adjacent annual values, visibly distinguished
from recorded equality. Selected crossing reports bounding time, keys, values,
matching home-equivalent units and run. Table and run JSON link remain available.

Geometry is static SVG projected 3D, with decorative depth/width and no continuous
animation or WebGL allocation. This bounds resources but is not hardware evidence.
No new social model or behavior: ODD inventory update unnecessary. Compared
`docs/models/README.md`, `world/models/housing/README.md`,
`world/models/housing/index.js` annual snapshot/ledger scheduling and
`world/decision/housing-ribbons.js`. Resolved discrepancy: household demand is an
event field in households, not housing_supply's home unit; conversion is explicit.
No model changes, population identities or cross-model mapping introduced.

The authored crossing fixture is synthetic test data, not an executed seed-42
model result. Separate tests run the actual model twice with seed 42 and verify
adapter determinism and nonmutation.

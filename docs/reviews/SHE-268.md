## Delivered

- `world/explorer-dock.js` opens `mountPlacePicker` instead of raw World controls.
- `world/place-picker.js` defines six versioned presets, authored SVG postcards,
  hooks, modal focus/dismissal, approximate world-map pin, existing
  `/api/date-places?q=` address search, explicit geolocation consent, error
  states, and coordinate validation under a disclosure. `place-picker.css`
  supplies full-screen responsive presentation and visible focus.
- Opening Choose a place and choosing a postcard are the two required clicks;
  selection navigates immediately. `placeURL` includes coordinates and seed,
  retains rendering preference and clears saved experiment/run identity.
- `world/render.js` consumes the URL seed as the existing legacy `runSeed` and
  animates high-altitude arrival to a close street view. Pointer interaction
  cancels animation; reduced motion opens directly at the destination.
- `world/canvas2d-world.js` consumes the same URL seed; this deliberately
  low-fidelity top-down fallback has no 3D camera flight.
- `world/index.html` hides legacy raw coordinate controls under Precise location.
- `world/sim.js` activity snapshots now report the effective run seed rather than
  only the town's coordinate seed. No model rules or scheduling changed.

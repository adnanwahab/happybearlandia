## Delivered local slice

`world/decision/edit-affordances.js` derives contextual actions using the exact
World edit validator and placement context. Shared `world-tools.js` opens existing
editors and previews. Its stylesheet displays a static scene overlay in World,
with native focusable buttons and minimum 44px height; Studio uses an inline view.
Sourced buildings are excluded even for colliding IDs. Only selected scenario
projects, selected ground fitting the default building footprint, and supported
housing policy inputs are advertised. Unsupported/missing input offers no action;
read-only removes the layer and its controls. Lifecycle teardown removes it.

This is a contextual selection layer, not a citywide highlight of every eligible
asset. No new parcel authority, model rules, input values, runs, entity mappings,
seeds, clocks or causal records were introduced. Model ODD descriptions do not
change: no simulation mechanism changed. Reviewed shared validator, proposal and
renderer contracts above against the implementation; no cross-model mapping claimed.

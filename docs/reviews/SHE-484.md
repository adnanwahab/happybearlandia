## Delivered slice

world/decision/prediction.js owns a frozen, session-local player prediction and a
separate resolved result. world/decision.html and studio.js reuse the existing
run controls and exact normalized recipe. Only a subsequent explicit run can bind
the prediction; previews and reopened prior results cannot reveal it. Only that
experiment can resolve it. Later reruns cannot rewrite either record. Reload
clears the page-session prediction; persistence/sharing is not implemented.

Comparison uses matched-seed final housing_supply means in homes. Exact equality
is a tie; unknown direction, missing/null/nonfinite observations, missing pairs
or incomplete batches are unscored. Recipe includes model versions, seeds,
horizon, scenario identities/inputs and batch size. Predictions never enter API
inputs, runs, clocks, entity records, RNG or provenance. UI states synthetic
limitations and uses native selects/buttons and an aria-live result. No animation
or additional simulation is introduced.

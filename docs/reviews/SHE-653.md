## Delivered contract and limitations

Area ingestion retains only two bounded raw material strings. The inspector reads
these from the exact original API record; only OSM provenance enables a
contributor-reported label. This is not a modeled construction classification.
Synthetic rows, absent tags and absent records remain unknown. Surface shading is
explicitly renderer-only and links render documentation. Source opens the existing
JSON details, including original entity identity. Text is emitted with textContent.
The feature is a static evidence magnifier, not a second rendered close-up viewport.

No model rules, inputs, RNG, coordinates, clocks, ODD social model contracts or
resident actions change. Code-to-contract paths checked: world/api.js,
world/geometry-inspector.js, world/material-microscope.js, world/render.js and
world/render/README.md. The missing-tag discrepancy is resolved by additive ingestion;
old cached source records intentionally remain unknown. Separate Canvas2D and
Population inspectors remain unsupported.

No additional loops, timers, global listeners or GPU allocations. Owned handlers
are node-local; replacement/removal makes them collectible. Refresh retains the
same panel and JSON nodes and restores focused controls. Each interaction samples
CPU duration and existing frame stats; no physical-device pacing claim is made.

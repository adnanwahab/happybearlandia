`processLocally` capability. Configure true before start; never fall back to a
cloud recognizer or install language packs. API basis:
[Web Speech on-device explainer](https://github.com/WebAudio/web-speech-api/blob/main/explainers/on-device-speech-recognition.md).

disposal and timeout abort listening; late callbacks are ignored. Closing clears

wording against executable scheduling; a nominal year is not continuous elapsed
annual simulation. No model scheduling or ODD description was changed in this audit.

has no page-level observer/timer/message-listener disposal. Its message handler
checks origin but not the active iframe's `contentWindow`; an obsolete same-origin
frame must not update a replacement selection. These are lifecycle risks to test
alongside the state handoff, not evidence of measured resource usage.

## Next integrated implementation slice

One coding worker, in this isolated branch. Dependencies in order:

1. Define a versioned legacy sample receipt and frozen rendering projection. Pin
   batch/run ID, source snapshot revision, model/rules versions, town geometry and
   identity, base and actual annual seed, plan/arm, sampled year, sampled minute,
   scenario conditions and source labels. Define exactly which retained fields
   can be rendered. Reuse immutable-store conventions where compatible. Do not
   claim resumable full-state replay from the longitudinal compatibility object.
2. Retain actual baseline/plan projections at sampling time through the worker
   and storage boundary. Bound record size/count, handle quota/write failures,
   and keep parents/revisions immutable. Tests must compare three retained samples
   with the corresponding executable `simulateYear` output.
3. Bind each distribution member to that receipt/checkpoint. Bin selection lists
   actual members; never choose a synthetic midpoint or substitute another seed.
   Display finite metric count / completed runs, missing outputs, and separately
   renderable / finite samples. A missing render checkpoint still counts as a
   finite metric observation. Reject duplicate identities and mismatched versions.
4. Add a frozen checkpoint mode at `/world/worlds.html` through normal chart
   navigation. Read only recorded supported fields and label synthetic results.
   Fail visibly for absent, corrupt or mismatched checkpoints, with no live
   fallback. Keep reconstructed live exploration explicitly separate. Pin seed,
   arm, sampled minute and year across navigation/reload.
5. Cancel superseded fetches and reject stale results. Dispose observers,
   listeners, timers and rendering resources on route changes. Bound active
   scenes for low-end devices. Use native keyboard controls and touch targets;
   avoid mandatory motion, including under reduced-motion preference.

Acceptance remains open: three real sampled outputs match rendered state and
clock; missing checkpoint is unavailable; zero/partial/nonfinite outputs have
correct denominators; immutable revisions survive rerun; rapid timeline/camera
navigation cannot install stale state; route disposal releases resources; desktop,
mobile and keyboard journeys pass. Capture before/after evidence on the actual
distribution and checkpoint routes, using disposable fixtures. Existing supplied
SHE-510 screenshots cover `/` and a synthetic World route, not this acceptance
journey, and were preserved unchanged.

`world/render/README.md`, `world/city/README.md`, the ODD inventory and City/Legacy
descriptions. `docs/architecture.md` is absent; README documents current authority

  Reusing this stage check would not satisfy the ticket's recorded-work gate.
  Pagehide disposal is wired in `world/render.js`; the layer owns shared geometry,
  materials and instanced meshes. There is no reduced-motion gate for its crews.

  `CONSTRUCTION_STARTED`, `TOPPED_OUT`, `PROJECT_COMPLETE` and delay events, with

  Construction stage can persist with zero progress because of weather or
  resource constraints. A start event is not proof of continuous later work.
- `world/hidden-systems/model.js` and PR #353's projection: a separate synthetic
  City replay can supply exact checkpoint events. It does not establish a
  mapping into daily World, nor a street-maintenance-specific observation feed.

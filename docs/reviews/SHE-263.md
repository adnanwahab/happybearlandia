  choosing a destination. `world/onboarding/explorer-progress.js` now initializes

  simulation state is stored or modified. Distinct steps are required in either
  order and repeated/unrelated actions cannot complete onboarding prematurely.

  paint over HUD pixels too. Screenshot CSS now hides only `#view canvas`.
  Interactive guide content is no longer masked. Only dynamic noninteractive

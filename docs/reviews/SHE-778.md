issue independent read/revoke capabilities, inspect through a World navigation
link, expire or revoke without touching its source. Owned files: world/guest/*,
new guest tests, minimal server/navigation hooks, export of existing bounded body
reader, this review and test receipt. Shared roadmap stays coordinator-owned.

Acceptance for this slice: exact pinned manifest retained; opt-in only; no list,
parent lookup or parent mutation; wrong-scope/tampered secrets fail; persistent
revocation and expiration. Limits: uploaded snapshots only, rights attestation
only, fork disabled. Authenticated source ownership and rights enforcement are
prerequisites for project-backed sharing and fork-to-own, not invented here.

SHA-256 hashes. Guest tokens cannot revoke. Uniform 404 denial avoids exposing
record existence. Capability only grants access to the explicitly uploaded
snapshot. Existing private APIs are unchanged; this is not a global private-API
authentication retrofit. Source model rules/scheduling unchanged, so no ODD model
addition applies. Existing Reality replay tests verify selected stored data can
be replayed and fabricated metrics fail replay. New page labels submitted metrics

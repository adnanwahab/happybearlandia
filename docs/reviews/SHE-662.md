## Delivered slice and decisions

`world/discovery-fog.js` derives cards from the loaded buildings' existing ID,
name, kind and finite area, explicitly labeling unavailable fields and synthetic
property limits. It introduces no resident actions, coordinates, discoveries,
causes, random choices, run data or social mechanism. The ODD inventory needs no
model change; the Legacy/Population state authorities, clocks and rules remain
untouched. Cosmetic inspection marks are not model knowledge.

`world/render.js` mounts the collapsed panel inside existing World controls,
reuses the normal building inspector, clears fog after successful card/list
inspection or normal building selection, and disposes on pagehide. The matching
stylesheet is loaded by `world/index.html`. The unmasked flat list includes the
same metadata and a full-inspector entry for each building. Existing essential
statistics remain in their normal inspectors/panels; no essential data is fogged
there. Missing API geometry continues to use its existing explicit fallback.

Fog is opt-in and static, with names/buttons left visible. Reset only clears
session inspection marks; checkbox choice persists until changed or reloaded.
No localStorage, URL, model or server write occurs. Failed/unsupported inspection
leaves the card masked, shows a retry message and preserves the flat alternative.
Reset/disposal invalidate late asynchronous completion. Native controls, visible
focus, 44px targets and wrapping/scrolling support mobile and keyboard use.
No transitions or animations require a separate reduced-motion fallback.

Final entry audit checked `world/renderer-entry.js`, `world/static-city-model.js`
and `world/static-city.js`: unavailable WebGPU redirects to a geometry-only
viewer. `world/static-city.js`/`.html` now reuse the same component against
`city.buildings` and existing `select` geometry inspector, with the same
pagehide cleanup. It creates no simulation or workers. Failed viewer state
rejects card inspection; missing graphics still uses the existing error UI.

Pacing instrumentation exposes synchronous DOM update duration and a bounded
two-frame repaint gap through `window.hblDiscoveryFog.getMetrics()`. It cancels
superseded/pending sampling and removes listeners on disposal. This is not a
scene FPS benchmark; no hardware-performance claim is made.

## Child evidence and gaps

### SHE-222 — Mechanism Microscope

Normal entry: `/world/future-machine.html` → rent WHY.
`world/future-machine/main.js` composes `decomposeRent` and
`renderRentDecomposition` from `rent-decomposition.js`. The calculation uses
`cityMetrics`' all-unit denominator, matches baseline unit IDs, and identifies new
inventory through `housingProjectBuildingId`. It rejects unmatched stock, missing
metrics, incompatible snapshots and reconciliation failures.

`test/rent-decomposition.test.js` verifies every month 0–120 at seeds 42 and 7,
nonmutation, zero control, malformed inputs and signed rendering. Month 0 has zero
components; seed 42 Month 120 has 36 existing + 24 new units / denominator 60,
and delta approximately −740.769 USD/month, reconciled within 1e-6. These are
synthetic model accounting results, not incumbent household savings. Integrated
browser coverage in `test/e2e/two-futures-sprint.e2e.js` remains to execute.

### SHE-194 — Fork from Any Moment / World Builder

Normal entry: `/world/living-city/` → World Builder.
`world/living-city/{builder,builder-panel,worker,page}.js` branch the displayed
City snapshot, retain its cloned parent, run both arms, show paired records and
allow entry and another branch. Transit capacity presets are bounded; horizon is
1–24 months. Synthetic cost/rule and unsupported real-world effects are labeled.

Four `test/world-builder.test.js` cases verify immutable input, repeatability,

rebranching but has no fresh execution evidence here. The ≥30% repeat-fork
first-time-player signal is unmeasured; no evidence establishes its model-rewrite
kill criterion.

### SHE-223 — Butterfly Ledger

Normal entry: Future Machine → metric WHY → Open Butterfly Ledger.
`world/future-machine/butterfly-ledger.js` runs four sequential matched-seed
ablation pairs using the existing City adapter. The default recipe is seed 42,
30 initial households, 120 months, district d1 housing amount 24, illustrative
cost 1,000,000, delay 0, compliance 1. Ablations use 12, 500,000, 12 and 0.5,
respectively. Each row has saved experiment, seed, model, initial hash, canonical
recipe SHA-256 and replay URL. Nondefault recipes are rejected.

`test/butterfly-ledger.test.js` reran actual engine and persisted API/reopen
checks. Observed delta is −740.769 USD/month. Contributions: amount −148.575,
compliance −148.575, delay −54.378, cost 0; residual −389.241. Integer thousandths
sum exactly. This satisfies displayed-precision reconciliation, not unrounded
exact attribution of floating-point results. The residual includes reference,
omitted and rounding effects as documented in `BUTTERFLY-LEDGER.md`; it is not a
pure interaction estimate. Required model-attribution labeling is present.

The residual is about 52.5% of the observed delta and exceeds every contribution;
amount and compliance tie. The kill-criterion concern is supported by fresh model
evidence. Product owner should decide whether to retire/rework this method before
expanding it. No evidence proves users can name a useful dominant input.
`test/e2e/butterfly-ledger.e2e.js` remains browser-blocked as recorded below.

### SHE-226 — One Life, Many Worlds

Normal entry: `/world/city-lab.html` → completed experiment → Enter future.

arms, at least 30 runs and month 0→120, then await 60 replay requests sequentially.

`test/city-life.test.js` verifies sequence/concurrency 1, 60 rows, seed wraparound,

```js
import {createDetectiveHandler} from './ops/detective/api.js';
import {mkdtempSync, rmSync} from 'node:fs';
import {tmpdir} from 'node:os';
import {join} from 'node:path';
const root = mkdtempSync(join(tmpdir(), 'she212-detective-'));
try {
  const handle = createDetectiveHandler({root});
  const call = async (path = '', body) => (await handle(new Request(
    'http://local/api/detective' + path,
    body === undefined ? {} : {method:'POST', body:JSON.stringify(body)}
  ))).json();
  for (let caseIndex = 0; caseIndex < 5; caseIndex++) {
    const {experimentId:id} = await call('', {caseIndex});
    const p = await call('/' + id);
    const choice = p.choices.find(c =>
      Number(c.label.match(/Authorize (\d+)/)[1]) === p.outcome.homes - 36);
    const r = await call('/' + id + '/answer', {choiceId:choice.id});
    console.log({caseIndex, homes:p.outcome.homes,
      choice:choice.label, correct:r.correct, evidenceSteps:r.evidenceSteps});
  }
} finally { rmSync(root, {recursive:true, force:true}); }
```

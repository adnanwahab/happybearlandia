explicit pinned demo request. It retains a 368 KB archive (complete initial state
and three step outputs/checkpoints) with a SHA-256 pin, Monthly City 1.1.0, seed
714 and 30 households. Assumptions are documented beside authoring code: zero
private parcel capacity, d1 flood risk one, severity-one flood in months 1–2.

Each inspector displays unmodified source JSON with exact archive pointer, native
month, run identity, model version and seed. The five records are housing matching
alternatives, transport link closure inputs/outputs, flood damage event, business
checkpoint demand/cost/viability, and household-linked RESIDENT_MONTH before/after.
Business viability uses existing demand-minus-cost; no closure is invented.
Inspector wording is authored flavor, outputs are synthetic model results, and
no empirical causal or geographic identity claim is made.

Progress only advances after the record has been placed in the open inspector;
buttons beyond the current stop are disabled. It is an ordered local prefix scoped
to the archive hash, never a trusted score. Reload revalidates source bytes before
resuming. Cancel/reset/replacement/pagehide abort or invalidate pending responses.
No fallback results on 404, timeout, mismatch or missing record. Storage denial
shows a session-only warning. bfcache return remounts the disposed panel.

Reviewed docs/models/city.md against world/city/{seed,engine,systems,residents}.js,
record.js and core/panel.js. Existing ODD rules remain unchanged; the added ODD
input note documents this fixture. The browser reads independent recorded state;

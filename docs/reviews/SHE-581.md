## Delivered behavior and contract

/world → Saved experiments → Private sticky notes. Save an experiment using the
existing explicit server save operation, then load notes for its saved checkpoint.
Notes themselves never make network requests or enter checkpoint/share payloads.
The selected entity is the saved selection, not the current live selection. A note
can also attach to the whole saved moment. New snapshots need an explicit save;
notes do not imply a checkpoint was captured at the instant text was written.

Local anchor: immutable experiment ID as run/checkpoint scope, checkpoint schema,
model version, exact modeled minute, saved entity type/ID or moment, and SHA-256
of the complete checkpoint. Legacy supports neighborhood-activity.v2; living uses
the existing strict Population checkpoint reader and resident identity mapping.
Missing entities, unsupported versions and unavailable saves fail closed. Imports
retain unmatched notes as visibly unavailable and never silently remap them.
The digest checks consistency, not authenticity or verified modeled outcomes.

Browser-only localStorage; 200 notes, 4000 characters each, 1 MiB JSON maximum.
Imports validate before atomic replacement and reject conflicting IDs. Quota and
storage errors are visible; no eviction. Literal textContent prevents markup
execution. Explicit file export/import, per-note deletion and confirmed delete-all.
Native labels/buttons/dialog, status announcements, focus outline, wrapping text
and scrollable responsive panel. No animation or GPU requirement for note controls.
Storage is origin-local, not encrypted or account-isolated. Same-origin scripts
can access it. Browser clearing deletes notes; exported files persist separately.
No tracking, authentication, live service or production credentials required.

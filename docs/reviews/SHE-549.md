## Audit and decisions

Read repository AGENTS.md, README, product design and implementation plan;
`docs/architecture.md` is absent. Checked household-week documentation,
RESIDENT_PLANS, Population ODD, House action catalog, task queue, runtime,
checkpoint/House restoration and existing week/integration/browser tests.
GitHub connector open-PR searches scoped to this repository for
`house routine weekly planner` and `SHE-549` returned no matches. This is a
keyword overlap audit, not a claim that every open PR was reviewed.

Reuse the existing Population authority, household/member IDs, fixed step,
seed, config and House action receipts. No model rules or version changes.
This is a command-scheduling adapter, not a new social model. Pin the opened
saved checkpoint, bypass House autosave restoration in planner mode, and restore
that exact checkpoint on each run. The normal House More menu links to the
planner. It does not overwrite the saved checkpoint or save results remotely.

Scope: clean, rest, read, music and cook, with canonical durations. Up to 64
blocks; seven days relative to the pin, aligned to the existing fixed clock.
Conservatively reject all household overlaps, including different residents:
this slice does not reserve shared-object capacity across simultaneous tasks.
Unsupported tasks/residents, inexact minutes and out-of-week durations are
rejected atomically. Every add/move/remove is undoable, including after a run.
Undo changes the draft only; it does not reverse elapsed simulation effects.
Rerun restores the pin. Drafts and receipts are page-local and disappear on reload.

Cooking advertises canonical six-per-serving cost; actual roster, resources,
needs, commitments, age, travel and object admission are decided at the scheduled
minute by the worker. Zero cash is retained as a value. Draft acceptance is not
an execution promise. Run receipts distinguish rejection from admission, retaining
actual cost, action ID and command provenance; admission is not completion.
Final savings are modeled synthetic results without a causal-effect claim.
No City/Population ID or clock mapping is invented.

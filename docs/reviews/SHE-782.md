## Delivered local behavior

Normal Future Machine entry now offers **Create comic strip recap**. Selection
is presentation-only and deterministic: months 0/24/60/96/120 plus first recorded
plan completion, deduplicated and sorted. Six panels each contain paired static
SVG inventory, date/month, exact metrics/units, complete building ID/floor text
and event sources, pinned recipe/hash/model/seed/provenance, and checkpoint links.
No external images, animation, WebGPU or additional simulation is required.
Missing history/identity returns unavailable; missing snapshots/metrics/events
are explicitly labeled. A failed new comparison keeps the prior identified run;
a successful replacement clears the prior recap. Render work is capped at 24
buildings per arm per panel; all identities remain in the text alternative.

The download is a self-contained HTML artifact with inline SVG, expanded source
text and print CSS. Print it through the browser after opening the download.
All content is escaped. Preview/download is local and explicit; no new storage,
upload, tracking or social sharing. The UI states rights responsibility and
local file deletion. Existing synthetic-generator assumptions and recomputation
limitations are preserved. Scope is the Future Machine monthly City adapter;
this does not assert a shared identity/clock with other simulators.

## Delivered and decisions

- `world/camera-route.js`: direct or lift/traverse/descend cubic spans, exact
  continuous slab collision checks, checked endpoint cuts and explicit unavailable
  states. Fixed 2,048-obstacle search ceiling and 1,200m height ceiling. Cubic
  smoothstep spans cannot overshoot their verified line segments; joins stop
  briefly instead of introducing unverified rounded corners.
- `world/render/camera-obstacles.js`: actual building mesh BufferGeometry bounds,
  cached local bounding boxes plus fresh world transforms; 3m conservative margin.
  Includes hidden LOD shells, excludes parks, fails closed on unsupported meshes.
- `world/camera-presets.js`, `world/render.js`: opt-in cinematic routing on World,
  shared frame loop, step validation, cancellation, reduced-motion cuts, existing
  Return/Follow behavior. No model or ODD rules changed.
- Tests, reproducible CPU benchmark and renderer interface documentation accompany
  implementation. Synthetic box fixtures are engineering inputs, not model evidence.

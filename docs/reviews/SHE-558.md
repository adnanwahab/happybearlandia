on `/world/house`: recipe preparation, genuine parallel kitchen cleanup, shared
meal and appreciation. The existing dispatcher owns inventory reservations,
servings, needs, relationship outcomes and attended task time. UI only displays
inspected stock/requirements and sends existing system commands. No private clock,
random draws, person IDs, second stove slot or household reward store was added.

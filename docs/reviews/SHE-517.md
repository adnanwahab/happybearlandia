## Delivered contract

- `world/storm/cutaway.js`: bounded pure selected-row projection and optional
  native details/DOM/CSS profile. Reuses `hazardTile` thresholds and missing states.
- `page.js`: passes the same depth array, arm, step, cell and provenance to both
  inspectors; column buttons select through the existing render path.
- Fixed 0–1 m above-local-ground scale, >1 m clipping arrow plus numeric depth,
  dry distinct from missing. Numeric readings round to 0.001 m; positive values
  smaller than half that precision use `<0.001 m`. Depth is always metres,
  independent of the separate drainage-capacity picker.
- Synthetic/no-forecast/uncertainty labels beside the mechanism. Ground is a
  schematic datum: no invented underground strata, real street geometry,
  observations, calibrated probability or certification.
- Universal 2D path needs neither WebGL nor Canvas2D; no added textures, network
  services, GPU resources, timers, camera or animation. Closed profile does no
  projection; current storm uses 32 column buttons, maximum supported grid 128.
  Horizontal scroll contains mobile columns; native buttons/details and retained
  controls across steps support keyboard use and reduced motion.
- `hazard-field.js` now exposes idempotent destroy. Pagehide stops playback and
  ensemble work, destroys inspectors and the existing renderer/ResizeObserver;
  persisted back/forward-cache return reloads the recipe/step route.

No simulation code changed. `docs/models/README.md` remains accurate: this is a
read-only environmental-result view, not a new social agent model or submodel.

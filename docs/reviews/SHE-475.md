  Curtain state is deliberately not included in v1 permalink or saved run data.

  camera. Exact picking chooses the visible arm without half-panel reprojection.
- Pointer capture supports seam dragging; a labeled native range provides keyboard
  and touch access. Work coalesces per animation frame without interpolated motion.
- Geometry compatibility fails closed for absent pairs, no shared identity,
  unsupported/ambiguous supplied footprints and conflicting common positions,
  polygons or source identities. Height changes and inventory additions are valid
  modeled differences. A changed footprint is conservatively unsupported.

  remain. Floating native labels are hidden during reveal, with exact inventory

  receipts, stored runs or provenance changed.

## Decisions and limits

Diagnostics are caller-supplied enumerated observations, distinct from milestone
counts and simulation events. No listeners or normal UI capture are enabled.
Null means unavailable, never inferred. Known model/data versions are allowlisted;
rules remain null until independently versioned rules are supported. Build is a
bounded Git SHA or null. Recipe evidence supports only the actual structured
bakery-v1 contract; it is never a URL or raw lab receipt. Lab free text, source
fingerprints, paths and findings must not enter this schema. Replay evidence
checks consistency, not independent replay equivalence. Synthetic scripted events
remain explicitly synthetic and cannot count as observed player errors.

Next integration requires coordinator-owned UI paths and an explicit consent
control; no real sessions collected or live acceptance claimed. Main risks are
future allowlist changes and callers falsely labeling evidence; validation cannot
establish truth of caller assertions. Downstream analysis is not implemented.

Existing merge configuration is preserved: auto-merge.yml requires repository/
main gating and HBL_GUARDED_AUTOMERGE_ENABLED for mutation; manual dispatch defaults
to dry-run. auto-merge.cjs requires current-head human approval and checks. No
one-vote quorum, auth, voting, revision, source identity or check changes. Remote
repository variable/branch protection values were not certified or changed.

## Delivered behavior and boundaries

- Closed optional Feedback disclosure within World controls; no automatic prompt,
  modal, reminder, survey requirement or session persistence. Native details remains
  closed on every entry, so no repeated prompt can interrupt the same session.
- Read disclosure, explicitly consent, then tap Wow or Confusing. Wow uses v1
  `favorite`; the default is World/exploring. The player may choose one of the
  existing feature categories. No feature is guessed from a model event or URL.
- Only `{version:1,consent:true,kind,moment}` is sent. Existing same-origin,
  strict-schema, 512-byte, private aggregate-only SQLite storage is retained.
  No session histories, identities, free text, seeds or saved data are read.
- Clear resets local choices and consent, aborts pending transport and ignores
  stale responses. Dismiss/close does the same; Escape returns focus to summary.
  Success resets consent; failure stays optional and warns about duplicate retry.
- Static DOM/CSS works independently of WebGL, reduced motion and renderer quality;
  buttons have minimum 44px height. No animation, timers for prompts, or simulation
  reads/writes/listeners were introduced. Only the existing request deadline runs.

**Clearing limitation:** individual withdrawal from already combined anonymous
counts is unavailable in the existing data contract. The UI discloses this before
consent. “Clear local feedback” clears local choices only, and cannot guarantee
cancellation of a count accepted before browser abort. If acceptance requires
withdrawal of sent counts, that remains an external product/retention prerequisite:
review a receipt/deletion contract and its privacy implications before widening
this slice. Do not claim complete feedback-deletion acceptance from these tests.
Counts represent submissions, not distinct people or representative measurements.

No ODD/model description changes are needed: the reviewed diff changes no rules,
inputs, clocks, entity mappings, seeds, outputs, provenance, or run storage. Files
checked against that boundary: world/player-feedback.js, world/index.html,
world/player-feedback.css, server.js, ops/player-feedback/api.js and its README.
No synthetic results or cosmetic effects are generated by the reaction component.

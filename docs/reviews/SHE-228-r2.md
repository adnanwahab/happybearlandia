## Twenty minimal experiments and their evidence

### 1. Newspaper delay desk

**V/T ingredients:** [buildEditions](../../world/newspaper/editions.js) already emits source-linked annual stories; [classifyConstraint / loadConstraintRun](../../world/laboratory/constraints/model.js) retain construction, utility, staffing and finance reasons ([newspaper test](../../test/living-newspaper.test.js), [constraint test](../../test/constraint-detective.test.js)). **H delta:** a newspaper section about recorded delays, rather than only the existing opening/completion/disaster templates. Dependencies: same-run event feed, classifier and newspaper presentation; no new model. Minimal experiment: add one classified delay story from the saved demo with its original event/month and inspector link. Accept if its reason and target ID match the source; unknown reasons remain unclassified and an empty feed produces no invented headline. Interpretation stays editorial; a delay event does not prove an aggregate effect.

### 2. Archaeology change-only replay queue

**V/T ingredients:** [buildLayers / loadLayers](../../world/civilization/archaeology/history.js) calculate changed descriptions and check exact demo checkpoints; [history test](../../test/city-archaeology.test.js) verifies construction/relocation/closure. **H delta:** next/previous navigation over an entity's actual changed layers, rather than reading the existing full list. Dependencies: existing layer output and causal checkpoint navigation; retain the current demo scope initially. Experiment: select a business and step only between its distinct layers, displaying source event or “no retained explanatory event.” Accept exact month/run links, no extra state recomputation, and explicit missing-month errors. Generalizing the loader to arbitrary runs is later work, outside the quick estimate.

### 3. Lock a policy prediction before the receipt

**V/T ingredients:** [learning journal](../../world/learning/journal.js) locks predictions before outcomes and falls back to volatile storage; [policy receipt](../../world/laboratory/receipts/receipt.js) supplies the matched 100-pair quest result ([journal tests](../../test/learning-journal.test.js), [receipt tests](../../test/policy-receipt.test.js)). **H delta:** predict the direction and frequency of the resident's commute improvement before revealing the receipt; the existing learning page and receipt remain distinct today. New dependency: a versioned round adapter keyed by complete receipt recipe, proposal, horizon and outcome definition. Experiment: one locked prediction followed by reveal/reload. Accept no outcome before lock, no second prediction for the same round, unavailable trips kept separate, and changed recipe creating a new round. No claim that forecast skill transfers to real policy.

### 4. Idea starter tournament on one contact history

**V/T ingredients:** [projectContacts](../../world/civilization/ideas/source.js) retains bounded actual saved contacts and truncation; [simulateIdeaSpread](../../world/civilization/ideas/model.js) is seeded and supports remix/fading; [existing page](../../world/civilization/ideas/page.js) already shows per-hop evidence/draws ([tests](../../test/idea-diffusion.test.js)). **H delta:** compare a small set of starter residents automatically against the identical retained source, instead of manually rerunning one starter. Dependencies: source checksum, fixed seed, eligible starters, bounded execution. Experiment: three eligible starters, one title/seed, show reached and active counts with the existing detail view. Accept deterministic rerun, no Population mutation, visible differing introduction minutes and truncated-source warning. This is conditional on recorded contacts; starters may begin at different first contacts, so the ranking is not a controlled estimate of social influence.

### 5. Policy interaction stability across seeds

**V/T ingredients:** [Merge Studio](../../world/invention/merge/README.md) computes baseline/A/B/AB and additive residual; [pairedSeedBand](../../world/research/paired-seeds.js) handles 3–32 unique seed pairs with Student-t bands and rejects missing outcomes ([merge tests](../../test/worldline-merge.test.js), [band tests](../../test/interaction-ablation.test.js)). **H delta:** show whether interaction direction persists across seeds instead of the existing single-seed diagnostic. Dependencies: four-arm runner, common per-seed initial state, browser-safe summary adapter and cancellable batch worker. Experiment: three seeds and two disjoint policies; compare AB-minus-baseline with the sum of A/B changes per seed. Accept agreement with hand-computed residuals, duplicate/shared-policy exclusion, trip denominators and missing-seed suppression. Pointwise synthetic-seed intervals are not empirical confidence, and differing commuter sets limit interpretation.

### 6. Future Search evidence-gap lens

**V/T ingredients:** [assessRun](../../world/civilization/futures/search.js) requires exact same-run positive rent/travel observations and compatible units; [contract](../../world/civilization/futures/README.md) declares catalog/stream limits ([test](../../test/future-search.test.js)). **H delta:** a compact reason breakdown for unavailable evidence, rather than only the existing missing/excluded/match assessment and coverage notices. Dependency: diagnostic return values from validation branches, preserving search semantics. Experiment: one valid run plus missing, duplicate, wrong-unit and empty-stock fixtures; show counts by reason. Accept identical match sets before/after, unavailable remaining distinct from false, and catalog truncation not described as complete coverage. Quick implementation is an explanatory lens, not expanded indexing.

### 7. Rent composition through time

**V/T ingredients:** [decomposeRent](../../world/future-machine/rent-decomposition.js) already reconciles existing-stock price plus new-unit composition and renders the selected-month microscope; [tests](../../test/rent-decomposition.test.js) cover 121 months, two seeds and unavailable states. **H delta:** plot those components across all retained matched months, with a selected-month link back into the existing inspector. Dependencies: immutable paired history and existing month selection; no new formula. Experiment: compute the component series and click the first nonzero composition month. Accept each total reconciling within the existing tolerance, unavailable points shown as gaps, no mutation and exact selected-month navigation. Components concern all units, including vacant ones; they are not household savings. Recheck newer remote Future Machine UI before integration.

### 8. Construction bottleneck relay

**V/T ingredients:** [Hidden Systems model](../../world/hidden-systems/model.js), [queues](../../world/hidden-systems/queues.js), [theater](../../world/hidden-systems/theater.js) already connect permits/resources to housing placement ([test](../../test/hidden-systems.test.js)). **H delta:** a project-focused chronological relay showing successive blocking stages, not another queue chart or capacity control. Dependencies: retained per-month project events/reasons and project IDs. Experiment: select one project and show its recorded blockers until completion. Accept original event ordering, no “dominant cause” inferred from counts, and explicit gaps where a month has no reason. This view describes scheduling evidence; changing a capacity may move the bottleneck elsewhere.

### 9. Atlas boundary comparison bookmark

**V/T ingredients:** [Atlas model](../../world/laboratory/atlas/model.js) already exposes normalized recipes, matched seed cells and exact sample reruns; [contract](../../world/laboratory/atlas/README.md) distinguishes finite-grid contrasts from tipping thresholds ([test](../../test/tipping-point-atlas.test.js)). **H delta:** share two adjacent selected cells and one common seed/month as a comparison bookmark. Dependencies: a small versioned two-recipe URL envelope and existing sample rendering. Experiment: bookmark adjacent cells with different majority classes and reopen both samples. Accept identical reconstructed metrics and seed, different parameters disclosed, and cancellation/incomplete cell excluded from class claims. No claim of an exact critical parameter.

### 10. Cheapest qualifying plan guessing round

**V/T ingredients:** [reverse search](../../world/invention/reverse/README.md) already screens catalog costs, evaluates compatible bundles and reports omissions/frontier ([test](../../test/reverse-simulator.test.js)); [prediction journal](../../world/learning/journal.js) can lock guesses. **H delta:** ask the player to guess the cheapest tested qualifying bundle before revealing the existing frontier. Dependency: round adapter that freezes target, budget, search bound, seed and policy catalog revision. Experiment: one guess and a bounded search reveal. Accept comparison against evaluated candidates only, honest “none found,” omitted-combination count and actual trip denominators. “Cheapest tested” must not become “globally optimal.”

### 11. Keepsake-to-journal memory trail

**V ingredients:** [family keepsakes](../../world/house/family-keepsakes.js) retain ownership/source information; [character journals](../../world/journals/README.md) archive actual activity by city/mode/run/person/day, with flush and retention boundaries (**T** journals). **H delta:** open related recorded days from a keepsake, rather than inventing a nostalgic backstory. New dependency: explicit mapping of keepsake owner/action/source time to journal identity; source-object provenance may not identify any journal entry. Experiment: one keepsake created during a journal-enabled preset run, link only an exactly mapped recorded day. Accept ownership transfer preserved, missing journal shown as unavailable, no cross-run name joins and no fabricated earlier life. Mapping feasibility remains unresolved; this is not quick.

### 12. Same-household financial branch comparison

**V/T ingredients:** [timeline braids](../../world/timeline-braids/model.js) enforce Population continuation and matching clocks; [firstDifference](../../world/timeline-braids/comparison.js) compares resident traits; [household risk](../../world/population/household-risk.js) requires complete reconciled daily payments ([braid test](../../test/timeline-braids.test.js), [risk test](../../test/household-risk.test.js)). **H delta:** compare one verified household's buffer history in sibling saves, beyond the existing home/employer/income traits. New dependency: household continuity validation; a resident moving households cannot silently carry the old household's finances. Experiment: two compatible sibling saves at one minute, with seven complete daily records each. Accept same-household check, history gaps staying unknown, and no cause attribution to the first differing action. Display observed trajectories, not an estimated action effect.

### 13. First invalid retained checkpoint finder

**V/T ingredients:** [auditCityCheckpoint / loadAuditMonth](../../world/civilization/debugger/model.js) validate references and resource-flow records; current debugger inspects one checkpoint ([test](../../test/reality-debugger.test.js)). **H delta:** scan a bounded retained checkpoint sequence and locate the first rejected/invalid one. Dependencies: ordered checkpoint catalog, existing API rejection handling and cancellation. Experiment: valid checkpoints around one corrupted fixture. Accept separate replay rejection versus semantic issue, distinct ordinary scarcity, and “first among retained checkpoints” wording. Do a linear scan: invariants may fail and later recover, so binary search is unjustified. Do not infer that the failure first arose at the sampled month.

### 14. Genome pair-interaction grid

**V/T ingredients:** [compareGenome](../../world/laboratory/genome/model.js) already runs edited/baseline trajectories and one-change-removal sensitivity ([test](../../test/world-genome.test.js)). **H delta:** a bounded two-factor matrix that distinguishes pair interactions from existing one-at-a-time effects. Dependencies: normalized recipes, versioned contrast definition, four runs per factor pair and shared seeds. Experiment: electric capacity × construction capacity at one seed, compute the four-corner residual for unhoused households. Accept exact recipe replay, zero residual for duplicate corners, missing outcomes unavailable, and no additive attribution asserted from leave-one-out results. Later multi-seed replication is separate from this minimal experiment.

### 15. Private closure consequence rehearsal

**V/T ingredients:** [fork engine](../../world/counterfactual/engine.js), [economic domain adapter](../../world/counterfactual/economic-domains.js) and [contract](../../world/counterfactual/README.md) support logistics-link closure → explicit business delivery → household projection ([test](../../test/counterfactual-fork.test.js)). **H delta:** an operator-local visual rehearsal of that existing tested adapter, not enabling public forks. Dependencies: authenticated private parent source, exact geometry/network/business/household allocation mapping, matched domain RNG streams; durable ownership/job storage for anything shared. Experiment: local fixture, one mapped link closure, show the baseline/child delivery and ledger changes. Accept immutable parent, same domain seeds, unauthorized read denial and unsupported mapping failure. Default service remains unavailable; no production activation is part of the proposal.

### 16. Sustained-outcome breakpoints

**V/T ingredients:** [breakpoints](../../world/invention/breakpoints/model.js) use [runPlan](../../world/invention/model.js)'s per-step stopping predicate; first-hit behavior already exists ([test](../../test/reality-breakpoints.test.js)). **H delta:** stop only after a condition holds for three consecutive completed months. Dependencies: new versioned predicate recipe and bounded counter, with missing observation resetting the streak. Experiment: compare a transient threshold crossing with a sustained one. Accept exact final month and all three source observations, no match across a gap, and deterministic rerun. Do not change existing single-hit semantics or treat concurrent events as explanations.

### 17. Perspective evidence-coverage matrix

**V/T ingredients:** [perspectives model](../../world/civilization/perspectives/model.js) selects four situations around one saved flood; [contract](../../world/civilization/perspectives/README.md) explicitly says beliefs/conversations/news access are unavailable. Accept identical event/run/month scope, unchanged-home check for the outside-district case and no inferred mental state. ### 18. Opt-in recorded-event sound cues

Experiment: export one month, import receipt, recompute mechanism, compare packet fields.

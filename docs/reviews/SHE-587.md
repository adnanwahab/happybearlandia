## Existing gaps and measured evidence limits

- `world/onboarding/accessibility.js` filters hidden/inert controls, traps only
  explicitly modal panels, exposes polite status and observes live reduced motion.
  Existing tests cover these mechanisms, not listening with assistive technology.
- Prior SHE-58 reports quick-demo contrast below 4.5:1. Current
  `world/first-run-guide.css` still uses `color: var(--bg)` on `var(--accent)`.
  Revalidate actual composited colors and both themes; historical token ratios
  are not new rendered measurements. Check text, disabled explanations, focus
  rings and control boundaries over moving scenes and in forced colors.
- Existing World browser smoke checks a media query and visible focus; it has no
  axe audit and does not assert canvas animation stops. No axe dependency or
  focused axe runner was found in package.json/tests. This acceptance item is open.
- No verified caption/transcript inventory covers the entire new suite. Link every
  audible outcome to equivalent text; distinguish cosmetic cues from model evidence.
- Preexisting `.mini-symphony-evidence/SHE-587-before*` captures and manifest are
  preserved. They are supplied baseline artifacts, not newly inspected accessibility
  evidence. No after captures or visual improvement claims were manufactured.

## Manual screen-reader record and completion protocol

Actual result: **not performed**; no browser/AT listening session was available.
There are no fabricated NVDA, VoiceOver or TalkBack results. A human evaluator
must record OS, browser and AT versions, input device, integrated commit, route,
scenario/seed, date, exact spoken output, expected result and pass/fail/gap for:

1. Portal Enter/back; arrival announcement and meaningful restored focus.
2. Radial/list open, action traversal, disabled reason, Escape and stale selection.
3. Lasso equivalent keyboard selection, aggregate/count explanation, empty/partial
   results and cancellation without changing model state.
4. Photo entry, all framing/export controls, receipt consent, export failure and exit.
5. Timeline month/chapter navigation, selected event evidence and missing checkpoints.
6. Gamepad opt-in/disconnect and complete equivalent keyboard journey.
7. Share preview/copy, permission denial, native cancellation and invalid reopen.

Run these at desktop and 390px width, both themes, forced colors and live reduced
motion; check focus is visible and unobscured and no pointer gesture is mandatory.
Axe needs an installed pinned browser integration with explicit route/state scopes
and zero unreviewed violations; supplement it with keyboard and real AT checks.
Reduced-motion acceptance must inspect camera/particles/transitions and static
progress, not merely matchMedia. Keep real run/recipe identity and synthetic versus
observed labels intact; do not disable model clocks to stop cosmetic motion.
